# Asset credits

## 3D models — Kenney (CC0)

All models under `models/` come from [Kenney](https://kenney.nl) asset packs and
are released under [Creative Commons Zero (CC0)](https://creativecommons.org/publicdomain/zero/1.0/),
which places them in the public domain — free to use, including commercially,
with no attribution required. Credit is given here anyway.

| Folder | Pack |
| --- | --- |
| `models/pirate/` | Pirate Kit |
| `models/watercraft/` | Watercraft Pack |
| `models/nature/` | Nature Kit |

Each pack's models share one `Textures/colormap.png` palette texture, which is
why the packs are kept in separate folders — the `.glb` files reference that
texture by a relative path.

## Everything else

The water shader, the fish meshes, the islands, the UI and all sound effects are
generated in code in this project.
