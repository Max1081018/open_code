# Low-Poly Nature Starter Pack

40 unique game-ready, flat-shaded low-poly nature props in one consistent style.
Free, CC0 - use them in anything, commercial or not, no credit needed (but appreciated).

## Contents
- 8 trees: 3 pines, 3 deciduous (one with a pale birch-style trunk), 1 palm, 1 dead tree (approx. 2.2-4.7 m tall)
- 8 rocks
- 6 bushes
- 6 grass tufts
- 4 flowers
- 2 stumps, 2 logs
- 4 terrain tiles (flat, hill, dirt, rocky)

## Formats
- GLB (recommended: Godot 4, Unreal 5, Blender and three.js import it natively; Unity needs the free glTFast package - see below)
- OBJ (fallback; vertex colors are embedded in the geometry - most editors that read
  OBJ vertex colors will show them, no separate material files needed)

## Conventions
- Real-world metric scale (trees approx. 2.2-4.7 m tall)
- Y-up, pivot at ground contact point - drop them straight onto terrain
- Flat-shaded vertex colors, no textures or UVs - nothing to set up
- Under 500 triangles per model
- One zipped download per format

## Import notes
- Godot 4: drag the .glb into the filesystem dock, instance it. Done.
- Unity: install the free glTFast package (com.unity.cloud.gltfast) via Package Manager,
  then drag the .glb into Assets. (Unity has no built-in glTF importer.)
- Unreal: use the built-in glTF importer (Datasmith glTF) or the OBJ files.
- Blender: File > Import > glTF 2.0 (.glb).

## How these were made
Every model is procedurally generated by a custom Python script (numpy + trimesh),
then each file was individually validated (load check, triangle count, ground
pivot) and rendered for the preview images. No stock, scanned, or third-party
assets are included. All 40 files are unique.
